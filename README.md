# Contact Book

A simple yet powerful contact management application that allows you to easily organize, add, and manage your personal and professional contacts.

## Features

✨ **Core Functionality**
- ➕ **Add Contacts** - Quickly create new contact entries with essential information
- 🗑️ **Delete Contacts** - Remove contacts you no longer need
- 👁️ **View Contacts** - Browse all your saved contacts
- 🔍 **Search** - Find contacts quickly and easily
- ✏️ **Edit Contacts** - Update contact information as needed

## Getting Started

### Prerequisites
- Your system must support the application runtime
- Administrator privileges may be required for initial setup

### Installation

1. Extract the `Contact Book App.zip` file to your desired location
2. Navigate to the extracted folder
3. Run the application executable

### Usage

1. **Adding a New Contact**
   - Click the "Add" button or menu option
   - Enter the contact's name, phone number, and email
   - Click "Save" to store the contact

2. **Deleting a Contact**
   - Select the contact you wish to remove
   - Click the "Delete" button
   - Confirm the deletion

3. **Managing Contacts**
   - Search for contacts using the search bar
   - Edit contact information by selecting and modifying entries
   - Organize your contact list efficiently
